# AWS Docs Reader 要件定義書

## 1. 概要

AWS公式ドキュメントを1〜2年かけて通読するための、個人用の進捗管理PWA。
本文は公式サイト(docs.aws.amazon.com)で読み、アプリは「次に読むページへの案内」と「読了記録」に徹する。

### 目的
- どこまで読んだかを迷わず把握できる
- スマホのスキマ時間に「次の1ページ」をすぐ開ける
- スマホとPCで進捗が自動で揃う

### 前提
- 利用者は自分1人
- 学習時間は週7時間程度
- 本文は保存・再配布しない(常に公式サイトの最新版を読む)

## 2. 対象範囲

### 対象
- 各サービスのユーザーガイド・開発者ガイド

### 対象外(MVP)
- APIリファレンス、CLIリファレンス、SDKドキュメント
- ホワイトペーパー、ブログ

### 初期の対象ガイド(優先順)
1. Amazon ECS 開発者ガイド(Fargate関連を含む)
2. Amazon DynamoDB 開発者ガイド
3. Amazon Aurora ユーザーガイド
4. 以降は設定ファイルに追加していく

## 3. 機能要件

### 3.1 目次
- サービス → ガイド → ページの階層で表示する
- ページの並び順は公式の目次順に従う
- 各ページにステータスと最終更新日を表示する
- 章単位で折りたたみでき、章ごとの進捗率を表示する

### 3.2 ステータス管理
ページごとに以下のいずれかを持つ。

| ステータス | 意味 | 進捗率への算入 |
|---|---|---|
| 未読 | 初期値 | しない |
| 読了 | 読み終えた | する |
| 要復習 | 読んだが後で読み直す | する |
| スキップ | リリースノートなど読まないと決めたもの | する |

- 目次上でタップしてステータスを変更できる
- 複数ページの一括変更はMVPでは対象外

### 3.3 次に読むページ
- ホームに「次に読むページ」を1件大きく表示する
- 選び方は、優先度の高いガイドから目次順で最初の未読ページ
- タップすると公式ページを外部ブラウザで開く

### 3.4 読了確認
- 公式ページを開いた後にアプリへ戻ると、直前に開いたページについて確認シートを表示する
- 選択肢は「読了」「要復習」「まだ途中」の3つ
- 一行メモを任意で入力できる

### 3.5 進捗表示
- 全体の進捗率と、ガイドごとの進捗率を表示する
- 直近4週間の読了ペースから完了予定日を算出する
- 記録が4週間分ないうちは、1ページ5分・週7時間で仮算出する
- 今週読んだページ数を表示する

### 3.6 復習
- 要復習のページを一覧で表示する
- メモ付きページを一覧で表示する

### 3.7 同期
- 4章を参照

### 3.8 バックアップ
- 進捗データをJSONでエクスポート・インポートできる(同期障害時の保険)

## 4. 同期仕様

### 方式
- GitHubのシークレットGistに、進捗データを1ファイル(`aws-docs-reader.json`)で保存する
- 認証は`gist`スコープのみのPersonal Access Token(classic)を使う
- 初回設定時、自分のGistから同名ファイルを探し、なければ新規作成する

### タイミング
- 起動時と、アプリが前面に戻った時に取得してマージする
- ステータス変更後、3秒待ってからまとめて保存する
- オフライン中は端末内に保存し、オンライン復帰時に送信する

### 競合解決
- ページ単位で`updatedAt`を比較し、新しい方を採用する
- 端末ごとに別ページを更新した場合は両方が残る

### セキュリティ
- トークンは端末内のIndexedDBに保存する
- スコープをGistのみに限定し、漏えい時の影響範囲を絞る
- シークレットGistはURLを知っていれば閲覧可能なため、メモに機密情報は書かない

## 5. データ設計

### 5.1 目次データ(ビルド時に生成、リポジトリで配信)

`public/data/guides.json`(ガイド一覧)
```json
[
  {
    "id": "ecs-dev",
    "service": "Amazon ECS",
    "title": "開発者ガイド",
    "baseUrl": "https://docs.aws.amazon.com/AmazonECS/latest/developerguide/",
    "priority": 1,
    "pageCount": 812,
    "generatedAt": "2026-09-22T00:00:00Z"
  }
]
```

`public/data/toc/{guideId}.json`(ガイドごとの目次、必要時に読み込む)
```json
{
  "guideId": "ecs-dev",
  "nodes": [
    {
      "title": "Amazon ECSとは",
      "url": "https://docs.aws.amazon.com/AmazonECS/latest/developerguide/Welcome.html",
      "children": []
    }
  ]
}
```

### 5.2 進捗データ(Gistと端末に保存)
```json
{
  "version": 1,
  "pages": {
    "<ページURL>": {
      "status": "done",
      "memo": "タスク定義とサービスの違いを整理",
      "updatedAt": "2026-09-22T10:00:00Z",
      "readAt": "2026-09-22T10:00:00Z"
    }
  }
}
```
- キーはページURL(ガイド構成が変わっても記録が残る)
- 未読ページは保存しない(データを小さく保つ)

## 6. 目次データの生成

- GitHub Actionsで週1回実行する
- 対象ガイドはリポジトリ内の`guides.config.yaml`で管理する
- 取得元は各ガイドの目次データ(`toc-contents.json`)を第一候補とし、取得できない場合はサイトマップ(`sitemap.xml`)にフォールバックする
  - ※取得元の形式はプロトタイプで要検証
- 生成結果に差分があればコミットし、GitHub Pagesに再デプロイする
- 公式側でページが消えた場合、進捗データは残し、目次からは外す

## 7. 画面設計

### 7.1 ホーム
- 次に読むページ(大きなカード、タップで公式ページへ)
- 全体進捗率と完了予定日
- 今週の読了数
- 要復習の件数(タップで一覧へ)

### 7.2 ガイド一覧
- 優先度順にガイドを並べ、それぞれ進捗バーを表示する

### 7.3 目次
- ガイドの階層目次
- 各ページ行にステータスアイコン、タップでステータス変更、長押しで公式ページを開く

### 7.4 復習
- 要復習とメモ付きページの一覧

### 7.5 設定
- GitHubトークンの入力と同期状態(最終同期日時)
- 手動同期ボタン
- エクスポート・インポート

### ナビゲーション
- 画面下部のタブで、ホーム・ガイド・復習・設定を切り替える

## 8. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応端末 | スマホ優先(iOS Safari、Android Chrome)、PCブラウザも対応 |
| オフライン | 目次と進捗の閲覧・更新は可能。本文はオンライン前提 |
| 表示速度 | 起動から次に読むページ表示まで1秒以内(キャッシュ時) |
| テーマ | ライト・ダーク両対応(端末設定に追従) |
| 認証 | アプリのログインなし。同期用トークンのみ |
| コスト | 0円(GitHub Pages、GitHub Actions、Gistの無料枠内) |

## 9. 技術構成

| 項目 | 採用技術 |
|---|---|
| フロントエンド | Vite + React + TypeScript |
| PWA | vite-plugin-pwa(Workbox) |
| 端末内保存 | IndexedDB(Dexie.js) |
| 同期 | GitHub REST API(Gist) |
| 目次生成 | GitHub ActionsのNode.jsスクリプト |
| デプロイ | GitHub Pages(Actionsで自動デプロイ) |

- GitHub Pagesのサブパス配信に合わせ、Viteの`base`を設定する
- 画面遷移はハッシュルーティングにする(Pagesでの404を避けるため)

## 10. マイルストーン

| M3 | 読了確認と進捗表示 | 戻り時の確認シート、完了予定日が動く |
